# Repository Documentation

Welcome to the repository documentation! This guide provides a structured, high-level overview of the Python concepts, data structures, and scripts included in this project.

## Core Python Fundamentals
*   **Data Types & Variables**: Covers fundamental operations, complex numbers, type conversions, and the use of booleans to manage logic as either true or false.
*   **String Manipulation**: Demonstrates string concatenation, formatted strings, escape sequences, and string indexing with start, stop, and stepover commands.
*   **Data Structures**: Provides methods for managing Lists, Dictionaries, Tuples (which are immutable), and Sets (unordered collections of unique objects).
*   **Comprehensions**: Explains the shorter syntax for efficiently creating lists, sets, and dictionaries directly from iterables.

## Advanced Functions & Memory
*   **Special Functions**: Explores higher-order functions like `map()`, `filter()`, `reduce()`, `zip()`, and anonymous one-line `lambda` functions.
*   **Decorators & Generators**: Details how to modify function behavior using decorators and generate objects sequentially using `yield` and `next()` functions.
*   **Memory Optimization**: Explains object interning, a technique where Python reuses memory cells for identical immutable items to improve performance.
*   **Copy Mechanics**: Differentiates shallow copies (creating a new object but sharing nested ones) from deep copies (recursively copying all nested items).

## Object-Oriented Programming (OOP)
*   **The Four Pillars**: Outlines Encapsulation, Abstraction (hiding functionality), Inheritance, and Polymorphism (same operation, different behavior) to design robust code.
*   **Inheritance Structures**: Details the implementation for Single, Multiple, Hierarchical, Multilevel, and Hybrid inheritance models.
*   **Method Resolution Order (MRO)**: Explains the exact sequence Python follows to execute methods during multiple or hybrid inheritance scenarios.
*   **Attributes & Methods**: Covers global and local attributes, the convention of using underscores for private variables, and the use of magic/dunder methods.

## File Handling & Exception Management

| Feature | Description |
| :--- | :--- |
| **File I/O** | Demonstrates reading, writing, copying, and appending files using the `open()` function and context managers like the `with` statement. |
| **Error Handling** | Shows how to gracefully handle runtime exceptions using `try`, `except`, and `finally` blocks. |
| **Custom Exceptions** | Explains using the `raise` keyword to manually trigger errors, such as a `ValueError`, when certain conditions are not met. |
